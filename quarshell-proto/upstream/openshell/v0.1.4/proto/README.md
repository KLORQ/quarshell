# OpenShell v0.1.4 protocol source

This is the pinned protobuf source set used for the Quarshell Go port. The files retain upstream SPDX headers and relative imports. `SOURCE.lock.json` records the exact source commit and SHA-256 for every copied `.proto` file. Do not modify this baseline copy; Go generation and Quarshell-owned API additions belong in a separate versioned target tree.

Source: [NVIDIA/OpenShell v0.1.4](https://github.com/NVIDIA/OpenShell/tree/v0.1.4).
