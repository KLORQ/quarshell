# quarshell-telemetry

Telemetry module boundary for Quarshell.

The OpenShell telemetry pipeline is not implemented in this module yet; the package is reserved for the planned independent telemetry component.

## Install

```sh
go get github.com/KLORQ/quarshell-telemetry@latest
```

## Development

```sh
go test ./...
```

Requires Go 1.27 or newer. See the [Quarshell documentation](https://klorq.github.io/sandbox.dev/) for product guides and compatibility status.
