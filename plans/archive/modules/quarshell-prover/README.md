# quarshell-policy/prover

Policy containment and risk analysis primitives for Quarshell.

The module provides solver-backed and symbolic policy analysis APIs.

## Install

```sh
go get github.com/KLORQ/quarshell-policy/prover@latest
```

## Development

```sh
go test ./...
```

Requires Go 1.27 or newer. See the [Quarshell documentation](https://klorq.github.io/sandbox.dev/) for product guides and compatibility status.
