# quarshell-driver-mxc

Windows MXC compute-driver module for Quarshell.

This module currently defines the package boundary only. OpenShell Windows MXC behavior has not yet been ported; see the compatibility plan in the [documentation](https://klorq.github.io/sandbox.dev/reference/openshell-compatibility/).

## Install

```sh
go get github.com/KLORQ/quarshell-driver-mxc@latest
```

## Development

```sh
go test ./...
```

Requires Go 1.27 or newer. See the [Quarshell documentation](https://klorq.github.io/sandbox.dev/) for product guides and compatibility status.
