# quarshell-supervisor

Host-side process and session supervision primitives for Quarshell.

The module manages process execution, session state and supervisor reporting across supported operating systems.

## Install

```sh
go get github.com/KLORQ/quarshell-supervisor@latest
```

## Development

```sh
go test ./...
```

Requires Go 1.27 or newer. See the [Quarshell documentation](https://klorq.github.io/sandbox.dev/) for product guides and compatibility status.
